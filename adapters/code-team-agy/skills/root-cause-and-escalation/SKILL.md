# Root Cause & Escalation（根因取证与熔断升级）

## 1. 铁律：证据与假设物理隔离
- **绝不把“可能原因”当成“需求”写进 brief**。
- 每次排查输出必须严格分两块：
  - `Verified Evidence`：实际运行命令、日志片段、精确 `file:line`；
  - `Unverified Hypotheses`：猜测列表 + 验证该猜测所需的最小实验命令。

## 2. 最小复现闭环（先红后绿）
1. 构造能 100% 稳定触发缺陷的最小复现命令或单测（**先确认它会红**）。
2. 用二分定位（`git bisect` / 模块隔离 / 报文回放）将根因收敛到具体函数与状态转换。
3. 修复后重跑最小复现（确认变绿）并跑全量回归，严禁只修表面症状（如加无意义 `sleep` 或吞掉异常）。

## 3. 阶梯熔断升级策略（防原地烧配额）
| 触发条件 | 强制动作 |
| :--- | :--- |
| Worker 同一编译/测试报错连续 **3 轮** 未收敛 | **立即停工** → 落盘报错现场与已尝试列表 → 移交 `Coder` 接管。 |
| `Coder` 在 **Gemini 4 Neon** 下连续 **2 轮** 未定位根因 | **禁止第 3 轮同模型空转** → 升级至 **`Claude Opus 5.5 High`** 或 **`Gemini 4 Carbon High`** 异构会诊。 |
| 跨模型升级后仍无法复现或缺少环境条件 | 立即停止自动试错，向用户汇报精确阻塞点与所需人工取证项。 |
